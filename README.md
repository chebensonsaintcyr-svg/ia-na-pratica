# IA na Prática — site estático

Site editorial responsivo em português sobre ferramentas de inteligência artificial. Feito com HTML, CSS e JavaScript puro: sem build, banco de dados ou custo obrigatório de hospedagem.

## Arquivos
- `index.html`: página inicial.
- `artigos/`: três artigos iniciais com títulos e descrições SEO.
- `styles.css`: visual responsivo.
- `script.js`: ano automático e comportamento demonstrativo do formulário.
- `robots.txt` e `sitemap.xml`: base técnica para mecanismos de busca.
- `privacidade.html` e `sobre.html`: páginas de apoio (revise antes de publicar).

## Visualizar no computador
Abra `index.html` no navegador. Para testar links e caminhos de forma mais fiel, use um servidor local, como a extensão Live Server do VS Code.

## Publicar gratuitamente pelo GitHub Pages
1. Crie uma conta no GitHub, se ainda não tiver.
2. Crie um repositório público chamado `ia-na-pratica`.
3. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**, escolha `main` e a pasta `/ (root)`, e salve.
6. Aguarde a publicação. O GitHub mostrará o endereço do site nas configurações do Pages.
7. Troque `https://SEU-DOMINIO.example/` pelo endereço real em todas as tags `canonical`, `robots.txt` e `sitemap.xml`.
8. Abra o site publicado e teste todos os links em celular e computador.

## SEO: checklist
- [ ] Trocar o domínio de exemplo pelo endereço publicado.
- [ ] Conferir títulos, descrições e links canônicos de cada página.
- [ ] Criar conta no Google Search Console e adicionar o site.
- [ ] Enviar `sitemap.xml` no Search Console.
- [ ] Publicar artigos originais, específicos e revisados, com fontes confiáveis quando necessário.
- [ ] Atualizar datas apenas quando o conteúdo for realmente revisado.
- [ ] Não esperar tráfego imediato: indexação e posicionamento podem levar tempo.

## Monetização
- **Afiliados:** cadastre-se apenas em programas legítimos, confira critérios, regras e taxas. Substitua links comuns por links aprovados e identifique claramente as comissões.
- **Publicidade:** aplique a redes de anúncios quando houver conteúdo suficiente e o site atender aos requisitos. Aprovação não é garantida.
- **Produto próprio:** crie um guia, modelo de prompt ou material útil e venda por uma plataforma que aceite seu país e método de pagamento.
- **Newsletter:** o formulário atual não envia nem guarda e-mails. Conecte um provedor de newsletter antes de coletar dados e atualize a política de privacidade.

## Antes de colocar no ar
- Substitua o domínio de exemplo em todos os arquivos.
- Atualize contato e política de privacidade para refletirem o funcionamento real.
- Verifique direitos de uso, informações, links e recomendações.
- Não prometa resultados financeiros nem apresente links como afiliados se não forem.
